Analytics as Code

A real analytics platform: ingestion, transformation, storage, testing, and an interactive dashboard, all shipped from a single Git repo. No orchestrator, no warehouse compute, no backend API.

This talk walks through a working system built with dbt-duckdb in CI, an Iceberg REST catalog as the only persistent layer, and a DuckDB-WASM dashboard querying native files directly in the browser. Over 1B records processed, with no servers to maintain.

Live demo: https://nemtracker.github.io/

Code: https://github.com/djouallah/analytics-as-code

Beyond the architecture, this session explores a broader shift toward "analytics as code" where pipelines, metrics, and even dashboards are version-controlled, reproducible, and fully automated using software engineering practices.

Main takeaway: every line in this repo was written by AI, except the tests. That part, I learned the hard way.
